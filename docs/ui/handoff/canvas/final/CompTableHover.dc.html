RuleBehaviour
Page orderAppBar crumbs → LiveBadge → header stats (one roving group) → timeline (one roving group) → RangeReadout buttons → tabs → filters → table (one roving group) → pagination.
Table roving↑/↓ move rows (focus = 2px range-yellow inset ring + hover fill + linked highlight on the timeline). Enter = row click. → / Tab moves into inner targets; ← / Shift+Tab back to the row. Home / End first / last row on the page.
Expanded rows→ on a collapsed prompt expands it, ← collapses; ↓ walks into its steps.
Tooltips by keyboardFocusing a row shows no tooltip (too noisy). Focusing an inner target or a cell that has one (Tab into the row, then ←/→ across cells with tooltips) shows it at once.
CopyNo hover copy buttons in rows. Tooltips are hoverable and selectable; the drawer keeps CopyButton (ids, curl, link); the expanded event JSON gets a CopyButton at its top right. No context menu.
