Tooltip · keyboard & accessibility
RuleBehaviour
role / wiringTooltip has role="tooltip" and an id; the trigger gets aria-describedby while it is open. No live region, except RangeReadout (aria-live="polite") which already announces brush changes.
focusEvery trigger is focusable or inside a roving group (timeline, tables, header stats). Focus shows the tooltip at once.
EscCloses the tooltip and keeps focus. A second Esc does the element’s own Esc action (e.g. clears the brush).
disabled controlsUse aria-disabled, not disabled, so they can take focus and explain themselves. Click does nothing.
touchTap a data mark: tooltip shows; tap again: click result. Long-press on cells shows the tooltip.
native titleRemoved everywhere. Native title stays only on the browser tab (document.title).
