LaneRule
Model(c) both. Within 16px of a mark (measured horizontally, in the hovered row for multi-row lanes) the nearest mark snaps; otherwise a lane readout at the guide’s time.
SnappedThe mark takes its hover style (§6B.4), its own tooltip opens, and a click does what clicking the mark does. The guide stays at the pointer (bar lanes: bin centre).
ReadoutTooltip/laneReadout: one line in --ink-muted (time · state), an optional hint line with the nearest mark. Same open delay as marks (120 ms). No click result: a click there clears the range (§11G.A8); a drag brushes.
SessionsSnap to the nearest band edge within 16px (any row, hovered row first). Inside a band’s span in any row → that band. Readout: 14:20 · no session open + hint nearest: <id> starts in Δ / ended Δ ago.
Prompt ticksSnap within 16px. Readout: 14:20 · no prompt + hint previous: #12 at 10:41 · 6m before.
Bar lanesNo empty space: the bin under the pointer always shows its tooltip, with 0 for empty bins. Click selects the bin either way.
Row lanes (presence, focus, device)Snap within 16px in the hovered row. Readout gives the state across all rows at that instant: 14:20 · focused / · away / · device asleep / · no session open.
Friction rowsSnap within 16px in the hovered row (cluster or single). Readout: 14:20 · no ▲ destructive nearby · 77 in view.
Network rowEvery instant is inside a segment or none: the segment’s tooltip (even when it’s too narrow for a label), else 14:20 · no network recorded.
Gap rowSnap within 16px to a hatch. Readout: 14:20 · all reported calls captured.
Guide & axis readoutUnchanged: the guide follows the pointer (bar lanes snap to the bin centre) and the axis chip shows its time, whether or not a mark is snapped.

PartRule
LayoutTwo-column grid per list. Name column = the longest name in that list (measured), capped at 400px; value column takes the rest. Padding 3px 12px per row; column gap 16px.
NamesOne line, never wrap: --ink, mono 12.5/18. Over the cap: middle ellipsis (anthropic-ratelimit-…-threshold) with the full name in the truncate tooltip.
PrefixesNo dimming (§11L.8): every name is --ink. Wire order is kept; no regrouping or sorting.
Values--ink-muted, wrap anywhere (overflow-wrap: anywhere): ids, JSON and URLs break across lines inside the value column only. No truncation in Raw. Redacted values --ink-faint.
Rows1px --line rule under every row; row hover --surface-raised across both cells (cursor default, text selectable). No zebra.
Summary tabIts short header list uses the same component (usually 4–8 rows, so the name column is narrow).

PartRule
FormatAbsolute time, not relative: updated 11:32:05 (HH:MM:SS, 24h, local). Always the same length, so nothing beside it moves. The relative age moves to the tooltip.
Slotwidth: 19ch (mono), left-aligned: a 10px indicator cell, 6px gap, then the text. The window control’s position never depends on it.
PollingA 6px --ink-muted dot in the indicator cell while a request is in flight (shown only after 150 ms, per §6A). The text does not change.
Failed✕ in --ink 600 in the indicator cell; the text keeps the last successful time. The reason and the retry are in Banner/refreshFailed under the app bar (existing). No longer text in the slot.
Across midnightOver 24h old: updated Nov 7 padded to the same 19ch.

ArrivalThe prompt row (or a friction cluster’s first prompt) becomes selected: --surface-raised fill plus a 2px --ink inset left rule, expanded and scrolled to centre. Its timeline tick shows the hover style while it stays selected.
How longUntil the next pointer-down anywhere, a tab or page change, or Esc. No timer.
