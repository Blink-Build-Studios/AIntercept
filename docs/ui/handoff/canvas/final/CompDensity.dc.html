StateRule
Cursorpointer on every element with a click result: buttons, segments, chips that toggle or remove, tabs, links, rows, marks, the brush ×. not-allowed when aria-disabled; progress when aria-busy. Never pointer on things that do nothing.
HoverFill --surface-raised and the border (or inset ring for borderless segments) rises from --line-strong to --ink-muted; text to --ink. Applies within 0 ms; transition --dur-fast.
PressedFill --skeleton (#20252a) on pointer-down, same frame (§6A.1).
Focus2px --focus ring (offset 1px, or −2px inside segmented controls).
Selected (segments, kind chips)--ink fill, --bg text, weight 600. Kind chips add ✓ and ring the swatch in --bg so the channel color still reads. 15.6:1 dark, 16.8:1 light. Selected + hover: --ink-muted fill (8.1:1 dark, 7.0:1 light with --bg text).
ContrastEvery state’s text keeps 4.5:1: hover --ink on --surface-raised 12.9:1; off chips --ink-muted on --surface 7.6:1.
