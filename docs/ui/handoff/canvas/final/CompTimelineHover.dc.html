TabEnters the timeline once (one tab stop), on the bin at the brush start, else the latest bin.
← / →Previous / next bin. On marker lanes (prompts, friction, permission ticks): previous / next marker. Bands and segments: previous / next one.
↑ / ↓Lane above / below; keeps the time.
Home / EndFirst / last bin in view.
EnterSame as click: select the bin, open the session, jump to the prompt, open the request, list not-captured calls.
Shift + ← / →Grow or shrink the selection from the focused bin (keyboard brush).
EscClose the tooltip; again: clear the selection; again: leave the timeline.
Focus visual2px range-yellow outline, 1px offset, on the bin column, band, segment or tick, plus the guide and its tooltip.
