{{ if or .Values.observer.autoscaling.enabled .Values.envoy.autoscaling.enabled -}}
⚠  AUTOSCALING IS ENABLED, which requires metrics-server in the cluster.
   DigitalOcean DOKS (and some other distros) do NOT ship it — without it the
   HorizontalPodAutoscalers stay stuck at minReplicas and report <unknown>.
   Check:
     kubectl get hpa          # TARGETS should show a % not <unknown>
   If missing, install it:
     kubectl apply -f https://github.com/kubernetes-sigs/metrics-server/releases/latest/download/components.yaml
   (deploy/digitalocean-bootstrap.sh installs it for you.)
